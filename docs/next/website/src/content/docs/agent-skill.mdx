Flockr ships a reusable agent skill file at [`skills/flockr/SKILL.md`](https://github.com/Rambarani/flockr/blob/master/skills/flockr/SKILL.md).

Install that file into any coding agent that supports reusable skills or custom instructions. The skill teaches the agent how to control Flockr from inside a Flockr pane.

Flockr also serves a separate guide at [`distribution/agent-guide.md`](https://raw.githubusercontent.com/Rambarani/flockr/main/distribution/agent-guide.md) for a different job: an agent helping a human learn, set up, or troubleshoot Flockr. The skill is for an agent operating Flockr; the guide is for an agent teaching a human.

## What the skill does

The skill tells an agent to use the `flockr` CLI when `FLOCKR_ENV=1` is set. That means the agent is running inside a Flockr-managed pane and can safely talk to the local Flockr socket.

With the skill installed, an agent can:

- inspect workspaces, tabs, panes, and neighboring agents
- split panes and run commands without stealing focus
- read pane output and recent logs
- wait for servers, tests, or another agent to finish
- start helper agents in sibling panes

The skill is a Markdown instruction file for agents. If Flockr is already installed, run `flockr --skill` to print the release-matched copy bundled with that binary.

## Install it

Install the skill with `npx skills`:

```bash
npx skills add Rambarani/flockr --skill flockr -g
```

If you installed the skill while it lived at the repository root, rerun this add command once instead of using `skills update`. The add command replaces the oversized copy and records the new location.

The `-g` flag installs it globally for supported agents. Omit `-g` to install it into the current project.

Use the repository copy as the manual fallback and source of truth:

```text
https://github.com/Rambarani/flockr/blob/master/skills/flockr/SKILL.md
```

For agents with a skill system, install that file as a skill named `flockr`. For agents without a skill system, paste the file into the agent's project or user instructions.

After installation, start the agent inside Flockr:

```bash
flockr
claude
```

Or use any other coding agent in a Flockr pane so `FLOCKR_ENV=1` is available to the agent process.

## Safety rule

The skill starts with one guardrail: if `FLOCKR_ENV=1` is not set, the agent should stop and say it is not running inside a Flockr-managed pane.

This prevents an agent outside Flockr from trying to control a session it does not own.
